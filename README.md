# Craving Corner - POS System

A modern Point of Sale system for Craving Corner restaurant.

## Features

- POS Terminal for order processing
- Order History with search functionality
- Inventory Management
- Food Products Management
- Sales Reports
- Customer Loyalty Program
- User Management
- Dynamic Theme System

## Development

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## Technology Stack

- Vite
- TypeScript
- React
- Supabase
- TanStack Query
- Shadcn/ui
- Tailwind CSS
